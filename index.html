UNDERSTAND THE DIFFERENCE

Windows host vs Linux guest

PowerShell commands run in the Windows shell. wsl.exe starts or invokes Linux through Windows Subsystem for Linux. Once inside Ubuntu, ls, pwd, cd and Linux paths apply.

Microsoft WSL reference ↗
LEARN THE BOUNDARIES

Not a substitute for real WSL

The simulator purposely omits programs such as gcc, pipes, processes, permissions, and real Linux filesystems. Later lessons will support a controlled local WSL companion without executing untrusted code on our website server.

INTERACTIVE LAB 002 / C PROGRAMMING

Memory, made tangible.

A variable stores a value. A pointer stores an address that can designate an object. Explore their relationship without touching real process memory.
